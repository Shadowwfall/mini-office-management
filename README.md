# Mini Office Management System

A lightweight web application for office administration, employee records management, and leave request tracking with live dashboard statistics.

## Tech Stack
- **Frontend**: React, Vite, React Router, Vanilla CSS
- **Backend**: Node.js, Express, `pg` (PostgreSQL client), Zod, JWT
- **Database**: PostgreSQL (Neon)
- **Deployment**: Render (Backend API), Vercel (Frontend SPA)

## Project Structure
- `frontend/` - React SPA client
- `backend/` - Express REST API
- `docs/` - Contract and architecture documentation
